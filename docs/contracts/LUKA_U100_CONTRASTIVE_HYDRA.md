# LUKA_U100_CONTRASTIVE_HYDRA / v1

Authority: [Hydra independent-fit plan](../plans/LUKA_U100_CONTRASTIVE_HYDRA_PLAN.md).
New execution artifacts use canonical content hashes, schema1, explicit parents
and the historical ALLJETS exploratory flags. Original scientific artifacts keep
their original contracts and bind the new execution hash.

- TRANSFER binds the original clean 431341db spec, original-source validation,
  exact setup/science IDs and accounting, completed result references and the
  original owner of OFFLINE keys. Files have safe relative destinations, byte
  counts and SHA256. Exact allowed payload: keys/manifest, keys/keys.npz and four
  report/prediction/receipt files per completed student. The manifest carries
  source evidence; original paths are never destinations or fallback reads.
- SPEC binds a personally verified transfer hash, existing pair-input manifest,
  matched reference, numerical PORTABILITY_EVIDENCE/v2, pinned new source, all
  twenty rows, reused/remaining partition, original recipe, site and storage.
  No pretrained student initialization and no changed stopping rule.
- TASK binds exact accepted jobs and immutable inventories. Setup requires
  original six real family miniatures, capacity/native parity, resource diagnostic
  and acceptance, plus imported-key and numerical-portability evidence. V2
  portability does not replace contrastive resource acceptance.
- REVIEW/PLAN/SUBMIT_CLAIM/DISPATCH_CLAIM binds the full prospective graph and
  measured plan. Remaining fits have zero dependencies; only report waits on
  terminal attempts. At measurement, only walltime may decrease. Existing exact
  DAG journals provide exclusive publication and exact accepted IDs.
- RESULTS binds authenticated predictions, site labels, selected epochs, original
  recovery anchors, matched-seed deltas and Hydra-replay delta. Completed reuse
  never includes a partial or missing-receipt row. No independent-test claim.

Target manifests, normalization and parent hashes remain untouched. Nonfinite,
changed inputs, invalid source or lineage failures stop; finite poor performance
is reported normally and never cancels independent rows. This adapter issues no
SPORC scheduler mutations.
