# Frozen adapter Hydra artifact contracts — v1

Scientific authority: `docs/plans/LUKA_FROZEN_ADAPTER_HYDRA_PLAN.md`.
Artifacts use `LUKA_FROZEN_ADAPTER_HYDRA_<KIND>/v1`, schema 1, canonical content
hashes and the existing ALLJETS exploratory-validation flags. SPEC binds source,
fixed recipe, both adapters, twelve students, authenticated input delta, original
transfer manifest and completed Hydra portability evidence. TRANSFER binds the
original pair spec and its authenticated M0HLT checkpoint/cache metadata.

Every transferred or published binary has a byte count and SHA256. Original
absolute paths are evidence only; Brown input loaders resolve allowlisted local
members. No raw reconstruction or SPORC path fallback. Full original source
replay occurs in its pinned original checkout, not in the importing checkout.

FIT records model role, all parents, ordered population, selected epoch, history,
loss weights, and deployment recipe. Teacher artifacts are marked privileged
oracles, not deployable HLT models. Teacher base tensors must equal M0HLT after
training. Student artifacts accept only HLT tensors. TASK receipts bind outputs
to exact journal-accepted job IDs. Partial outputs without a receipt are not
reusable. No automatic retries or overwrite of existing runs.

SETUP/ACCEPTANCE records installed Weaver/environment, GPU identity, numerical
replay, production miniature evidence and measured resource bounds. Submission
requires a complete dry plan and exact pushed clean source. Scientific quality
is never an admission condition. Failure, nonfinite math, source drift and bad
lineage are distinguished from finite disappointing results.
