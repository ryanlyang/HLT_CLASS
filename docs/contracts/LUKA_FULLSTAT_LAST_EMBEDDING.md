# FullStat final-rung embedding contracts v1

Authority: [plan](../plans/LUKA_FULLSTAT_LAST_EMBEDDING_PLAN.md).
Prefix `LUKA_FULLSTAT_LAST_EMBEDDING_*/v1`; canonical content/parent hashes,
immutable completion-last publication, FullStat sealed-test flags.

- RECIPE fixes FullStat 20 epochs, TRAIN normalization/tap/head and KD/aux coefficients.
- ANCHOR reuses original-source FullStat authentication and additionally binds
  the completed D033 reducer manifest. Trial banks are never accepted.
- GATE binds exact clean source, parent, node, site, resources and storage.
- BANK binds selected OFFLINE checkpoint AND report, prepared fingerprint,
  recipe, ordered TRAIN IDs/labels, 128 FP32 standardized targets, 128 FP64 moments.
  Compact D033 probabilities independently bind original report/identities/T2.
- PREFLIGHT binds exact real job, environment/GPU/backend, bank files, probes,
  all support maxima, parity, native readback, full-population measured timings.
  Failed gates cannot create science specs. Technical weights never initialize
  science. Metrics never gate quality.
- SPEC binds accepted gate and exactly one fresh fit plus aggregate.
- TRAINING_REPORT requires 20 epochs, unchanged schedule/selection, native
  head-free deployment and exact validation IDs/metrics.
- EPOCH stores current model (including predictor), optimizer, RNG, best native
  state, history and update count under exact gate/bank/source parents; payload
  digest commits last. No partial epoch or automatic resume is accepted.
- TASK/RESULTS bind selected native checkpoint, full predictions, all epoch
  history and recovered fractions against authenticated historical controls.
- PLAN/CLAIM/journal bind exact argv, dry review and explicit authorization.
  Missing/ambiguous scheduler acceptance is never silently retried.

No final-test operation, validation target export, bank reinterpretation,
shared-data cleanup, changed view builder or attention dependency exists.
