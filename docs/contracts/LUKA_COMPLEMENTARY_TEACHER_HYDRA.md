TE compares the actual classifier's sensitivities at both deterministic input
streams. Reference parameters, BatchNorm scales and masks are detached. Eval
mode/math SDPA/FP32 are restricted to the explanation passes; CE remains the
original BF16 train path. Microbatch accumulation is weighted by row count and
followed by one optimizer update. Masks exclude padding and symmetric pairs
are counted once. Input taps must match the installed factory; unsupported
layout, disconnected required gradients or nonfinite quantities fail closed.
No model parameter or BN running statistic changes during the explanation
measurement itself. Finite coordinate perturbations are diagnostics only.

OOF helper fits cannot accept a validation argument. Their ordered training
IDs must equal the registered complement. Training reports select the last
epoch, never a held-out score; the held-out forward happens after fitting.
Reusing full-data T0 weights as fold initialization is forbidden. Joining OOF
predictions verifies exclusions, exact checkpoint/fit/task ownership, coverage,
labels and ordering. TF weights never use development validation. Source IDs
and fold membership remain metadata, never model features.

Every student uses the exact D000 HLT cache and independent prediction heads.
Teacher banks contain only TRAIN embeddings with independent FP64 moments and
population std floor .001. Native deployment state is strictly `mod.*`, reloads
into the unchanged installed ParT, and reproduces selected predictions. Final
teachers all use native OFFLINE views and classification outputs. T0 is fresh,
not an assumed reuse of an earlier teacher. S0 is the matched student control.
