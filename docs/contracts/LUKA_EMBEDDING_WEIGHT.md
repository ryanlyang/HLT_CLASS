# LUKA_EMBEDDING_WEIGHT_* / v1

Authority: [plan](../plans/LUKA_EMBEDDING_WEIGHT_PLAN.md).

New records use canonical hashes, exact parents and the existing explicit
exploratory/no-independent-test flags. Existing AUX and LADDER records remain
unchanged and are not interchangeable with these records.

The current execution registration is SPORC tier3 for both the preflight and
all three scientific fits. Scientific recipes and schemas are unchanged;
the serialized execution-site/source hashes distinguish this registration.
An old debug gate/plan is rejected, not edited or automatically transferred.

- RECIPE fixes CE coefficient 1 and one of 0.75/1.5/10 auxiliary coefficients.
- GATE binds source, original matched CE/OFFLINE anchor, completed original
  embedding import, three nodes, resources and storage allowance.
- ARM is a derived, hashed per-weight execution identity under the same gate.
- TRAINING_REPORT/FIT bind exact recipe, bank, population, native checkpoint
  and selected predictions; technical probes cannot initialize science.
- PREFLIGHT binds all three full-epoch probes, weight-specific stress,
  native parity, environment and measured per-arm time requests.
- SPEC binds accepted gate evidence and three scientific tasks.
- PLAN/exact journal bind all reviewed commands and explicit authorization.
  Only verified COMPLETED/0:0 preflight accounting admits science.
- SCIENCE/RESULTS bind each completed fit and recomputable comparisons.
  Pending/partial fits are not reported as completed.

The immutable imported AUX/v1 bank keeps its original recipe hash (0.3);
that hash authenticates target construction, not the new student's loss weight.
The new recipe explicitly records this distinction. Every TRAIN join checks
ordered jet identities and labels. Results use local compact reference copies;
runtime must additionally authenticate the shared original bank and source.
