# Frozen C diagnostic v1

Authority: [implementation plan](../plans/CMS2JC2_FROZEN_C_DIAGNOSTIC_PLAN.md).
Additive CMS2JC2_RESPONSE kinds: DEV_C_DIAGNOSTIC, DEV_C_REUSE,
DEV_C_ACCEPTANCE, DEV_C_SHARD, DEV_C_REPORT and DEV_C_SUMMARY, all v1.
Every artifact is content hashed, parent bound and final_test_accessed=false.
The fitted response artifact is unchanged; interventions are explicitly labeled
diagnostic-only and must not masquerade as fitted/qualified response models.

Canonical variant registry, replicas, tasks, sample identity, donor receipts,
source semantics and numerical environment are revalidated before execution.
FULL is byte-identical to the production generator; all variants preserve its
categorical topology/identity draws. Diagnostic traces are transient. Only
aggregate counters/histograms/figures may be published. Out-of-support, clipping,
low statistics and poor closure are reported, not used to filter jets or fail
science. Corrupt inputs, nonfinite execution, different topology, source drift,
forbidden access and failed numerical replay fail closed.

Historical shard replay requires exact bin/population/identity counts, with
rtol=atol=1e-10 only for saved floating moments across CPU kernels. FULL versus
the production generator within each evaluation remains exact particle-array
and flag equality.

Generic DEV_STUDY/PLAN/OUTPUTS/submission journal contracts are reused. No
permission to modify a donor, open final test, fit a new model or use JetClass2
HLT is granted by this diagnostic registration.
