# Teacher particle prediction contracts v1

Authority: [scientific plan](../plans/LUKA_PARTICLE_TEACHER_HYDRA_PLAN.md).
New artifacts use `LUKA_PARTICLE_TEACHER_HYDRA_{KIND}/v1`, schema_version1,
content hashes, exact parent hashes and existing exploratory-development flags.
No previous artifact is renamed or reinterpreted.

SPEC binds the twelve-arm recipe, additive source snapshot, original A6000
qualification and selected teacher_m16 proof, environment, HLT population,
U100 jet targets, encoder/delta identities, resource limits and output allowance.
Original parent authentication runs in the original199928da worktree process.
New source changes must be additive relative to cc55765a; existing runtime remains
untouched. The prior uncommitted shared-message guard fix is not a dependency.

TARGETS binds SPEC, selected teacher report, U100 encoder and prepared identities.
It records fixed128-row TRAIN oracle extraction, full block6/block8 target
array SHA256s, HLT identity/offset hashes, real-particle count, channel count and
TRAIN-only FP64 mean/std with floor1e-3. Dense FP32 arrays are allocation-local;
only metadata persists. Subsequent supervised allocations rebuild the targets
and must match setup's complete metadata before training. No stochastic teacher,
native-forward shortcut, validation targets, particle assignment or padding
statistics are admitted. Controls never open privileged particle views/weights.

FIT binds SPEC, recipe, prepared HLT and U100 jet bank; supervised fits also bind
TARGETS, encoder and selected teacher report. TRAINING_REPORT records all30epochs,
same-seed initialization and sampling, every component loss and within-jet
variance, HLT-only selection, selected deployment replay and final probabilities.
Two target depths have separate heads with mean loss. Centered supervision has
equal full/centered terms. Every exported model is the native HLT model only.
EPOCH files authenticate provisional progress. TASK binds exact scheduler ID,
FIT/epoch/checkpoint/prediction bytes and campaign ownership. Completed report
assembly verifies saved predictions and selection without new model inference.

ACCEPTANCE binds TARGETS, warm and freshly measured production FIT receipts for
every arm, installed environment, GPU identity, preparation peaks, timings and
resource limits. Memory includes target construction. Runtime uses warmed full
batches, preparation once,2x fit projection plus900s. Technical miniatures are
not scientific fits. Finite poor metrics and low target variance never reject
admission. Corrupt data, nonfinite values or resource exceedances fail closed.

PLAN and SUBMIT_CLAIM bind reviewed commands and original authorization. Separate
bootstrap/science journals and exclusive live claims forbid duplicate or blind
partial submission. Complete-stage finish is idempotent; ambiguous stages stop.
Setup -> CPU release and fits -> report are the only scheduler dependencies.
CPU workers authenticate Hydra compute/default/normal, one requested CPU/task,
one node,4000MiB, no GPU, and one or two allocated CPUs matching controller TRES.
GPU workers require one RTX A6000,6CPUs,32000MiB and completed measured acceptance.
No new scientific performance or independent-test claim is implied by readiness.
