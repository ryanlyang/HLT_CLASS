# LUKA_AUXILIARY_GRID/v1

Authority: [active twenty-fit plan](../plans/LUKA_AUXILIARY_GRID_PLAN.md).
All new artifact kinds use LUKA_AUXILIARY_GRID_<kind>/v1, schema1, canonical
content hashes, exact parents and existing exploratory trial flags.

- RECIPE: exact20 arms, CE0.5, separate total KD/embedding weights, fixed
  temperatures/reductions/seeds/schedule, registered relation recipe.
- REUSE: completed original c50 ancestry/teachers/resources. REFERENCE binds
  completed strong K5/E5 result and optional target source in original source.
- SPEC: both imports, fresh source snapshot, counts,22-task wave DAG,4GiB quota.
- BANK preserves LUKA_TRIAL_HYBRID_BANK/v1; imports preserve exact bytes and
  teacher identity, with independent new ownership. BUNDLE binds all four.
- ACQUISITION records authenticated reuse or normal-retirement re-export.
  Corrupt/missing unretired files, wrong teacher or partial cleanup fail closed.
- STARTUP records native parity, gradient isolation, three registered corner
  probes and max-support resource evidence; no standalone preflight.
- TRAINING_REPORT/FIT/TASK bind30 epochs, per-teacher raw/weighted losses,
  relation beta, selected native checkpoint/prediction readback, exact jobs,
  dependencies and exhaustive outputs. Sum in registered teacher order.
- PLAN/CLAIM: targets,20 fits in ten afterok waves, report; immutable dry review,
  exact authorization and exclusive claim before live submission.
- RESULTS includes pending arms, full-validation/original50k metrics,
  recoveries, deltas versus c50 and retained K5/E5. No independent test claim.
- RETIREMENT/COMPLETE: only four new owned payloads after all20 results validate;
  exact-path/hash intent/completion. Results remain usable after retirement.

Never reinterpret original strong/multiteacher recipes under this namespace.
