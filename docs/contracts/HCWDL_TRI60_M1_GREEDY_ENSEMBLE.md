# HCWDL TRI60 M1 greedy ensemble contracts

The `HCWDL_TRI60_M1_GREEDY_ENSEMBLE_* /v1` family binds a validation-only,
source-pinned diagnostic to one completed 20-condition TRI60 M1 screen.

The source lock authenticates the screen campaign, aggregate, completion,
source lock, all 20 selected checkpoints/reports and validation metrics, the
original TRI60 source, foundation, recipe, graph, and `LOGIT_D000E` teacher
metrics. Path existence never authorizes reuse.

Prediction-shard contracts bind the exact four-candidate assignment, selected
checkpoint hashes, common ordered validation identities and labels, FP32
probability bytes, role, size, and no-final-test assertions. A killed worker
may reuse a previously published NPZ only when recomputation is byte exact;
different bytes fail closed.

The result contract fixes uniform probability averaging, FP64 accumulation,
the three greedy objectives, deterministic tie-breaking, five-member maximum,
singleton metric reproduction, storage bounds, and complete paths from size
one through five. The result is exploratory, cannot automatically choose a
finalist, and cannot control campaign completion based on performance.

The campaign and command-plan contracts register five sibling GPU inference
jobs and one CPU reducer, nice 10000, exact source-pinned workers, no source
scheduler dependencies, and no writes into either source campaign.
