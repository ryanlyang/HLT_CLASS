# FullStat final-rung replacement gate contracts v1

Authority: [plan](../plans/LUKA_FULLSTAT_REPLACE_GATE_PLAN.md).
Prefix `LUKA_FULLSTAT_REPLACE_GATE_*/v1`, canonical hashes and explicit parents.

RECIPE/GATE bind unchanged shared gate math, FullStat20, exact three nodes,
source, authenticated original anchor/cache/bank, Oscar resources and quota.
SPEC binds an admitted PREFLIGHT and the five-job DAG. Original trial flags,
warm starts, dense targets and final-test operations are not admissible.

FIT/TRAINING_REPORT bind node, fresh initialization digest, source gate,
supervision, all20 epochs and selected full-gated state/predictions.
EPOCH retains optimizer/RNG/history/model/best state, publishing its digest last;
there is no automatic retry or partial-epoch continuation.

BANK wraps COMPACT_BANK (same numerical layout as the trial, new FullStat
identity without trial holdout flags) with selected PRIV_D000 FIT/checkpoint/report and explicit
technical/scientific identity. TRAIN IDs/labels/counts/prepared parent must match;
9 FP32 factors per particle are authenticated before resident loading.
Native original D033 probabilities retain their existing authenticated contract.

PREFLIGHT authenticates runtime, native/gate parity, six actual support stresses,
three complete technical epochs, compact export/readback, all outputs and measured
time/RAM/GPU/storage. Exact successful submitted job identity is required.
TASK receipts recursively bind dependencies, selected artifacts and targets.
RESULTS replays saved validation metrics with oracle/HLT labels and recoveries.
PLAN/journal/CLAIM prevent unreviewed, duplicate or uncertain automatic retries.

No mutation of old worktrees, checkpoints, runtime packages or shared cache.
No quality-based cancellation. Deployable state includes the self-gate and
rejects external context.
