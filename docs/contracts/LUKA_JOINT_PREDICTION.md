# LUKA_JOINT_PREDICTION / v1

Authority: [plan](../plans/LUKA_JOINT_PREDICTION_PLAN.md).

Every artifact uses this distinct family, schema1, canonical content hash,
parent hashes and original exploratory ALLJETS flags.

- RECIPE: two native taps, independent heads and TRAIN normalizations; CE1,
  jet4, token3; aligned/Hungarian; fixed30/batch128; HLT-only headless inference.
- ACCEPTANCE: exact original token spec and source, passed prior preflight,
  successful exact-job accounting on replay, completed token comparisons,
  frozen teacher and whole-jet comparator. No new preflight implied.
- SPEC/PLAN/CLAIM: exact clean pushed source, acceptance hash, immutable
  weights/data/seeds/resources, two debug science jobs and explicit direct
  authorization. Prior token projection plus registered allowance, not a new
  measurement. No performance threshold or silent resource cap.
- BANK: single TRAIN-only U100 export binds teacher/prepared/recipe parents,
  alignment, ragged FP32 tokens.npy, raw FP32 jets.npy and index.npz containing
  ordered identities/labels/offsets and separate FP64 means/scales. Raw token
  payload must equal accepted original. No validation normalization/targets.
- TRAINING_REPORT/FIT: complete30-epoch schedule; raw CE/jet/token and weighted
  losses, full-validation selection, native-only checkpoint and readback.
- SCIENCE/RESULTS: exact accepted job, environment/GPU, output hashes, retired
  scratch declaration, same targets/reference populations across arms, recomputed
  validation/original50k metrics and recoveries. Missing complete receipt means
  pending/incomplete, not successful science. Saved descriptors authenticate
  historical payload identity, not availability of retired scratch contents.

Large banks are scratch-only; output references and selected models are retained.
No new final-test role or operations exist. Old contracts remain unchanged.
