DEV_B_TRACKING_DEBUG_REUSE, DEV_B_TRACKING_DEBUG_RETIREMENT. Existing B tier3,

ledger, original frozen comparison, new DEV_B_REUSE evidence, and successful
old acceptance result/receipt. All old scientific source bytes and numerical

DEV_B_TRACKING_SHARD/REPORT kinds with the NEW stage parent hash.

new stage, reviewed command plan and original ledger; records exact task-to-job
mapping and non-success terminal states, plus COMPLETED/0:0 acceptance.

PENDING-only cancellation. Unknown/running/completed targets fail closed.
Every live submit authenticates this receipt and freshly checks old scheduler
states. Immutable evidence and actual output bytes are checked at worker start.

All artifacts retain content/parent hashes and final_test_accessed=false. There
is no change to sample membership, generation, RNG, diagnostic comparisons,
storage limits or scientific decision rules, and no manipulation of C jobs.
