# Full-population D20 RAW Hydra contract

Authority: [scientific implementation plan](../plans/LUKA_D20_FULL_HYDRA_PLAN.md).
Owned namespace `LUKA_D20_FULL_HYDRA_*/v1` distinguishes this campaign from all
historical miniatures, wide Oscar ladders and hardware benchmarks. All records
carry canonical content hashes, explicit parents and development-validation /
sealed-final-test flags. No final-test inference capability is exposed.

SPEC binds exact clean pushed source, transitive repository donor hashes,
installed environment and backend, transfer/producer, original extended scalar
roles, full audited wide population, twenty draw epochs, batch256/LR1e-4,
three seeds,23 fits/92 five-epoch segments, policies and initial output estimate.
Changing scientific/resource fields and merely rehashing a spec is rejected.
The imported population retains its original audited namespace/hash; the new
recipe/spec bind it without changing memberships or reusing scientific models.

STARTS binds three untrained native/predictor/decoder tensors and component
hashes. Same-seed controls and variants load matching applicable components.
INITIALIZATION, EPOCH, TRAINING_REPORT, METRICS and RESULT bind fit/task,
population/starts, actual same-campaign teacher bank and TRAIN normalizer.
Epoch updates, draws,144-cell exposure, losses, readouts and selection replay.
RESULT is completion-last, including selected native checkpoints, ordered
validation predictions, diagnostics and any outgoing teacher bank.

The root artifact schemas are v1. Imported technical policy structures retain
their explicit owned INPUT_EXECUTION_POLICY/v2, STORAGE_POLICY/v2,
WORKER_LAUNCH_POLICY/v3 and EARLY_GPU_POLICY/v3 versions. They are exact SPEC
fields, not interchangeable with policies from older namespaces. Before data
decoding, a separate fifteen-minute srun probes four physical Pascal GPUs using
NCCL_P2P_DISABLE=1, Gloo control objects, known tensor collectives and real
installed-Weaver/independent-gradient parity. It also performs two actual
global256 backward/AdamW updates with synthetic inputs at authenticated TRAIN
maximum native and decoder support. EARLY_GPU_MEMORY/v1 receipts bind each
rank's peak/capacity, shape, batch, steps and finite loss; all must fit88% VRAM.
Failure releases no science and occurs before the full particle builds.

ACTIVATION_EXECUTION_POLICY/v1 is mandatory in SPEC. It binds FP32 native
encoder/stateless-block non-reentrant recomputation, unchanged batch256,
preserved dropout RNG and disposable BN/SyncBN replay buffers. The original
buffer references/counters update once; all model/optimizer tensor keys and
native inference remain unchanged. The independent full-graph reference has
recomputation disabled. Old specs without this policy are rejected by this
source and require a fresh execution; no old qualification is silently reused.

QUALIFICATION requires all13 objective arms and all registered seed miniatures,
complete physical particle support, aggregate host/GPU memory, full-validation
timing, a measured five-epoch fit envelope and exact serialized next-update
resume equivalence. Only real four-GPU proofs authorize CPU release. Technical
teacher values are explicitly marked synthetic; science allocations separately
miniature-check their actual authenticated bank and reload canonical starts.

PLAN/INTENT/SUBMISSION_RESPONSE/SUBMITTED bind actual shebang script arguments
and exact accepted scheduler IDs. Full dry review uses the actual script,
never a wrap placeholder. Exclusive writer locks and intent-before-submit
journals reject duplicates and uncertain responses. Workers verify site,
job/name/comment/source, resources, typed physical GPUs and accepted task IDs.
Independent fits have no artificial serial edge; a segment depends on its
predecessor, and the first student segment on its teacher's final segment.

Each EPOCH commits a full restart state after validation: model/decoder,
AdamW, teacher EMA where applicable, history/selected native states and every
rank's CPU/CUDA RNG. The sampler and schedules replay from immutable seed and
draw epoch. A following segment resumes this same fit, not a fine-tune or fresh
run. Incomplete epochs are replayed. Obsolete state retirement is journalled
only after a newer epoch is durable, inside that exact fit. Final restart state
is retired only after all RESULT payloads authenticate.

TASK receipts for segments reference durable endpoint epoch commits, plus the
final RESULT where applicable. They never reference obsolete restart payloads.
Recovery preserves earlier receipts and completion evidence, authenticates
terminal accepted jobs, skips successful segments and writes separate recovery
receipts. Export-only recovery from epoch20 performs no further updates.
Missing or ambiguous submissions fail closed; no other job is cancelled.

Only eligible TRAIN enters reconstruction moments/targets, outgoing banks and
BN recalibration. New TRAIN moments freeze once; later builds apply that exact
qualified record after scoped numeric comparison. Banks contain unique ordered
TRAIN IDs, selected same-seed EMA05 checkpoint/report parents and T2 probabilities
or standardized128-dimensional targets. Rank-partitioned mmap writes avoid
large object gathers. Fixed65536-row two-pass FP64 moments define standardization.
Only a completion-last BANK manifest authorizes reuse of its checksummed arrays.

RAM-only inputs are role-bounded and allocation-owned; counts are complete.
The complete retained-view/conversion scratch peak is checked before starting
any view, so insufficient /dev/shm space fails before expensive partial builds.
HLT forward receives features/vectors/mask only. Dataset/scientific source and
historical artifacts remain read-only. Validation remains natural, uses no
reconstruction target and selects RAW independently of diagnostic rejections.
Reports include classR50/R30/passing counts,600--2600 diagnostics, same-seed RAW
anchor recovery and paired seed summaries; poor metrics never fail a row.

Admission requires24GiB results plus2GiB spare initially; no automatic HOME
recheck or runtime cap occurs. The initialized conservative inventory is
14,748,932,625bytes, including concurrent restart/staging states. Genuine write
errors propagate while the previous committed state remains reusable. Cleanup
is restricted to exact owned job scratch and authenticated obsolete state.
