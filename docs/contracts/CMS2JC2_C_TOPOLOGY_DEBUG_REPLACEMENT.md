# Frozen C topology debug replacement v1

Authority: `docs/plans/CMS2JC2_C_TOPOLOGY_DEBUG_REPLACEMENT_PLAN.md`.

Additive CMS2JC2_RESPONSE v1 kinds: DEV_C_TOPOLOGY_DEBUG,
DEV_C_TOPOLOGY_DEBUG_REUSE and DEV_C_TOPOLOGY_DEBUG_RETIREMENT.
Original C/B, fitted response, acceptance, histogram and report contracts do
not change. The original C topology plan's scientific meaning remains binding.

The new stage binds a fresh debug study, exact original C topology subject,
acknowledged six-job ledger/journals, completed acceptance/receipt, and original
frozen C_L comparison through DEV_C_REUSE. Source, numerical environment, data,
policy, ranges, views, replicas and privileged-state flags are authenticated.

Exactly four independent 36-CPU/128-GiB/8h evaluations and one 1-CPU/32-GiB/4h
report are registered. The latter depends on the four new IDs. Original workers
publish DEV_C_TOPOLOGY_SHARD/REPORT with the new stage hash, unchanged scientific
fields, and the same complete population including unresolved/unestimable jets.

Retirement binds the new stage/plan and original ledger, exact five task IDs,
non-success terminal scheduler states, and COMPLETED/0:0 acceptance. Explicit
phrase/plan authorization and debug admission precede pending-only exact-ID
controller cancellation. Active/successful/unknown targets or existing old
evaluation/report receipts fail closed. Live submit rechecks old scheduler
states; worker startup verifies retirement and all reused receipt/output bytes.

Every artifact has content and parent hashes, immutable atomic publication,
schema version 1 and final_test_accessed=false. This extension never modifies B,
original C artifacts, matching or inference semantics, nor qualifies a response.
