# LUKA_EMBEDDING_PREDICTION_*/v1

Authority: [active plan](../plans/LUKA_EMBEDDING_PREDICTION_PLAN.md).
All new records have schema1, canonical content hash, parent hashes and the
existing exploratory ALLJETS flags. The original imported ANCHOR retains
LUKA_EMBEDDING_LADDER_ANCHOR/v1 and its original validator, not a new meaning.

RECIPE/SPEC bind four fresh coordinate-specific students, CE1+embedding5,
fixed30 batch128, original seeds, exact source and debug resources/support.
TEACHER binds native selected checkpoint, selected fit report and validation
predictions; origin is original_anchor or this_campaign, with a technical flag.
Only U000 can be original_anchor. No auxiliary predictor state is loadable by
the native teacher. New teachers bind the current SPEC and exact selected fit.

BANK binds recipe/prepared/TEACHER, TRAIN role, teacher coordinate, native tap,
rows, width128, exact ordered uint8 Nx32 identities/int64 labels, FP32 Nx128
standardized targets and FP64 moments. It is not a logit bank or a fixed-OFFLINE
bank. Source checkpoint is hashed before/after export. Consumers require the
registered immediate predecessor and reject technical/scientific mixing.

TRAINING_REPORT contains all30 epochs (one only for marked technical probes),
loss components, LR/updates, complete validation metrics and selected epoch.
FIT_REPORT binds selected native checkpoint/readback to that report and its
incoming bank. Outgoing bank TEACHER binds this selected checkpoint/report,
never the final epoch or auxiliary head. Results retain every completed row.

TASK receipts bind exact SPEC/dependency hashes, real journal job ID and an
exact output inventory. Setup includes every technical fit/bank, maximum-
support witness, parity, initial teacher readback and measured admission.
Science receipts include native model/report/predictions and outgoing bank
except at final D000. Publication is immutable; incomplete folders do not
authorize reuse. No automatic retries or partial resumes.

PLAN/CLAIM/journal bind the five-job afterok DAG to explicit authorization and
canonical dry review. Results revalidate retained compact artifacts and metrics
without model loading or particle decoding. Model/input/source corruption,
wrong roles, nonfinite values and lineage drift fail closed; poor science does
not. There is no final-test operation in this package.
