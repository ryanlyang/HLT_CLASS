# LUKA_DEPTH_RECOVERY v1

Authority: [operational plan](../plans/LUKA_DEPTH_RECOVERY_PLAN.md).
Canonical hashes, schema1, exploratory ALLJETS flags on every new artifact.

- STOP_PLAN/STOP: immutable original spec reference, exact original journal,
  accounting snapshot, explicit pending-only scope, hold/recheck before cancel,
  preserved dispatch races, exclusive cancellation intent and per-job evidence.
- SPEC/CLAIM: original scientific identity plus new execution source; exact
  authenticated reused receipts; never-started cancelled remainder; exclusive
  original output-namespace owner. No source/spec/receipt rewrites.
- PLAN/SUBMIT: full two-lane debug graph, distinct afterok science/afterany
  capacity dependencies, no preflight/shared exports/cleanup, exact authorization,
  dry-run resource checks and durable exclusive submission journal.
- TASK: new accepted job and recovery/original/scientific-parent hashes; exhaustive
  original-root scientific output references. Costs additionally bind recovery.
  Scheduling-only predecessors are NOT scientific receipt parents.
- RESULTS: same rows/populations/metrics and original50k report-only subset,
  distinguishing authenticated original reuse and new execution. Explicit pending
  rows permitted; no automatic payload retirement or claim of independent test.

Old LUKA_SUPERVISION_DEPTH artifacts retain their original versions and meaning.
Scientific kernels and recipes are imported byte-identically, not monkeypatched.
