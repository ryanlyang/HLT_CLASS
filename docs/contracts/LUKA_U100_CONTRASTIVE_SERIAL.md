  exact pending-only cancellation IDs, preserved active fits, ordered remaining

  exact-ID cancellation, never a broad name/user cancellation. Wait for old

  remaining rows partition all20 original arms. Debug, one active fit, no setup

- **PLAN / SUBMIT_CLAIM:** final exact dry/live plan and existing exact-DAG

  diagnostics. Durable immutable native-only best state plus checksum, epoch,
  metrics and spec parent. BEST files are not completed-fit or optimizer-resume
  receipts and survive later interruption.
- **TRAINING_REPORT / FIT / TASK:** validate first stopping boundary, actual
  epochs, policy, unchanged learning rates/update counts/losses/population,
  best-selection key, selected probabilities and native reload. Successful
  early stopping publishes normal completion. Task receipts bind accepted job
  IDs and inventory every published artifact. No auxiliary head is deployed.
- **RESULTS:** authenticated original and new rows, explicit original30/patience5
  regimes, actual epoch counts and stop reasons, matched-seed deltas, original
  historical recovery anchors, full-validation selection, overlapping report-only
  original50k, explicit missing-receipt rows. No independent-test claim.

The user-authorized patience policy terminates finite poor fits successfully;
it never fails a scientific row or cancels independent successors. Resource,
nonfinite, input, source or lineage failures still fail closed. Partial outputs
are preserved and any registered fresh retry uses a distinct root.
