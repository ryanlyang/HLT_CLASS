# FullStat fine-tuning contracts v1

Authority: [active plan](../plans/LUKA_FULLSTAT_FINETUNE_PLAN.md).
All new artifacts use LUKA_FULLSTAT_FINETUNE_KIND/v1, schema1, canonical hashes,
explicit parents and original FullStat role flags. Old contracts remain unchanged.

- REUSE binds exact completed fine-tail source/spec/task, selected DE000 native
  checkpoint/report/predictions, original seven TRAIN banks/bundle, references,
  original environment, hardware and support evidence. No teacher substitution.
- SPEC/RECIPE bind one fit, ten extra epochs, frozen-native three-pass head
  calibration, fresh AdamW, low cosine schedule, full3M/500k split, exact unchanged
  CE0.5/K1/E40 supervision, epoch0-inclusive checkpoint selection, storage and
  runtime. This is explicitly not exact optimizer/RNG resume from the old job.
- STARTUP binds disposable native/Weaver parity, CE-only main gradients,
  connected finite head gradients, max-support batch128, memory and bounded
  timing. No full preflight job or empirical scientific-performance gate.
- INITIALIZER records frozen-native calibration and the complete calibrated
  state. Its native state must match the authenticated selected parent exactly.
- EPOCH binds each completed epoch report to full model/optimizer/RNG state.
  TRAINING_REPORT binds all10 rows, unchanged epoch0 metrics, selection among
  0-10, best-new result, absolute sampler epochs21-30 and reset optimizer.
- TASK binds selected native/full state, final predictions and all epoch
  snapshots. Metrics must agree after native checkpoint readback. Completed
  expensive states exist before final checks; partial output is not overwritten.
- RESULTS compare original M0HLT/OFFLINE/fine-tail DE000 and continuation, with
  AUC recovery and R30/R50 at the same selected checkpoint. No inference in
  results inspection; test remains sealed. Parent epochs and added epochs are
  never portrayed as equal training budgets.
- PLAN/CLAIM/LAUNCH_* register one exact pushed-source job, complete dry review,
  explicit authorization, no requeue, exclusive journals and no automatic retry.

Local readiness and reused acceptance do not guarantee production memory,
runtime, or improved recovery. Inline Oscar technical admission is mandatory.
