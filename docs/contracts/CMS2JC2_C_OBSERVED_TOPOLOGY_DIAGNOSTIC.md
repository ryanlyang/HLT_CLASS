# CMS2JC2 observed-topology C diagnostic v1

Authority: `docs/plans/CMS2JC2_C_OBSERVED_TOPOLOGY_DIAGNOSTIC_PLAN.md`.

New `CMS2JC2_RESPONSE_* /v1` kinds (without the displayed space):

- `DEV_C_TOPOLOGY`: exact six-task registry, study and frozen reuse hashes,
  association-recomputed flag, diagnostic-only/privileged-state declaration.
- `DEV_C_TOPOLOGY_ACCEPTANCE`: lineage, selected count, codec closure,
  exact free replay and two-process sufficient-statistic parity.
- `DEV_C_TOPOLOGY_SHARD`: lineage, shard index, ordered membership hash, six
  histograms and their explicit counts, unresolved reasons, conditional coverage,
  free/fixed/observed mechanism counters, selected fixed residual-bin counts,
  codec maximum errors and missing continuous-module counts.
- `DEV_C_TOPOLOGY_REPORT`: exactly four authenticated shards, merged sufficient
  statistics, comparisons/accounting/plots, no automatic winner or qualification.

Reuse the unchanged `DEV_C_REUSE/v1` as evidence of importing the frozen model
and inputs without recomputing its calibration associations. The new stage
explicitly recomputes **evaluation** associations; it never refits the response.
Existing C reports and generation contracts are not reinterpreted.

Every artifact has content hash, parent hashes, schema version 1 and
`final_test_accessed=false`. Shard/report parents are stage, response, samples
and ranges. Outputs use atomic immutable publication and authenticated receipts.
Raw-pair libraries, target arrays, per-particle traces, labels and JC2 reads are
forbidden in durable outputs. Counts/coverage are not matching accuracy.

Resolved/comparable membership is determined only by registered association
resolution and availability of continuous modules. No cut on prediction quality.
Both fixed variants share the same comparable population and observed state;
only residual noise differs. Unresolved/unestimable populations remain visible.
Missing residual support uses the explicitly counted frozen central prediction;
missing continuous modules do not silently substitute identity or observed HLT.

Codec closure uses exact categorical equality and rtol=atol=1e-8 for p4/tracking;
energy uses the bridge's nonnegative-mass projection for source-rounding
spacelike inputs, with its raw-energy correction recorded separately.
It checks coordinate bookkeeping, not physical correspondence. Free generation
must match the original C evaluator on every registered jet; historical floating
moments and process-order sums permit rtol=atol=1e-10, not changed bins/counts.
Source differences are restricted to the already registered execution-only
surface and new diagnostic files; original scientific source remains frozen.
