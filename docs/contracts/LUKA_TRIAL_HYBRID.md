# LUKA_TRIAL_HYBRID v1

Authority: [active plan](../plans/LUKA_TRIAL_HYBRID_PLAN.md). All records use
canonical content hashes, schema1, explicit parents and exploratory ALLJETS
flags. Existing scientific contracts remain unchanged.

- RECIPE binds arm, stage, exact teacher order, per-epoch CE/KD coefficients,
  independent weight5 mean embedding objective, T2, fixed30 schedule and seeds.
- SPEC binds clean pushed source, complete original-source ACCEPTANCE, identical
  prepared population,22-job graph, storage/resource policy and no new preflight.
- TEACHER binds spec, original/shared or exact arm/stage origin, selected native
  checkpoint/report hashes and view. A same-named different-arm model is invalid.
- BANK binds teacher descriptor, exact TRAIN uint8 Nx32 IDs/int64 labels, prepared
  hash and NPZ file hash. Embedding values FP32 Nx128, mean/scale FP64 width128,
  minimum scale1e-3; logits FP32 Nx11 normalized T2 probabilities. No validation
  targets or normalization. Manifest retains moments after payload retirement.
- BUNDLE binds registered ordered embedding BANK hashes and immediate KD BANK.
  All IDs/labels join exactly in order; no positional-only or class-only joins.
- TRAINING_REPORT/FIT binds recipe/bundle/spec/node, all30 passes and weighted
  losses, native-only selected checkpoint, native probability/metric roundtrip.
- TASK binds all dependencies, exact accepted Slurm ID and exhaustive output
  references; published last. Ancestor failure/missing receipt blocks children.
- PLAN/CLAIM uses exact reviewed hash and22-job explicit authorization, canonical
  dry ledger, exclusive live claim and durable accepted-job journal. No requeue,
  broad cancellation, controller or automatic ambiguous retry.
- RESULTS includes every completed row and pending rows, selected epochs, AUC,
  accuracy, recovery, and QCD rejection at50%; original50k report-only. No quality
  threshold selects runs or changes the plan. No independent test claims.
- RETIREMENT intent contains exact own-root TRAIN target payload file references;
  COMPLETE is published only after all registered payloads are gone and models,
  predictions, reports/manifests remain intact. Results after retirement validate
  saved descriptors and retained payloads, NOT availability of removed targets.

Bad hashes, nonfinite data, input/teacher/source/role mismatch fail closed. Weak
finite science completes. No model receives privileged embeddings as inputs.
