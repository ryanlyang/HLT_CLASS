# FullStat last-rung attention contracts v1

Authority: [plan](../plans/LUKA_FULLSTAT_LAST_ATTENTION_PLAN.md).

`LUKA_FULLSTAT_LAST_ATTENTION_{RECIPE,ANCHOR,GATE,SPEC,PLAN,PREFLIGHT,TASK,
BANK,TRAINING_REPORT,RESULTS,SUBMISSION_CLAIM}/v1` use canonical content hashes,
parent hashes and immutable completion-last publication. No trial contract is
relabelled or accepted as a FullStat parent. Flags explicitly retain the sealed
test and unverified event/trial-overlap limitations.

Anchor binds original spec/source, all completed parent artifacts, selected
D033 checkpoint/report, reference predictions, unchanged scientific source,
foundation/cache, environment and backend. New nodes inherit original D000
initialization/sampler seeds. No technical checkpoint may supervise science.

Bank binds checkpoint/report SHA256, prepared hash, TRAIN role and ordered
identities/labels/counts, D033 coordinate, T2, block7 surface and FP32 payloads.
Only D033 export and D000 consumption/self-readback are allowed. Matrices retain
real squared support without padding; corruption, missing shards, reordered
rows, different source/parents and zero/nonfinite probability rows fail closed.

PREFLIGHT binds gate, source/environment/GPU/allocation, complete payload audit,
per-role support maxima, both one-pass fits, zero-weight parity, checkpoint
readbacks and resource projections. Only exact successful gate journal/accounting
admits SPEC. Science receipts bind dependencies and all payloads; selected
predictions must reproduce report metrics and authenticated validation IDs.
Reports preserve exactly20 passes and the original selector/schedule. Result
reader reports pending rows without using partial fits, recomputes retained
validation metrics and M0HLT/OFFLINE recovery, and includes both arms regardless
of scientific quality. Test evaluation is not implemented.
